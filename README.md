# 🚚 Fleet Pulse — نظام متابعة حركة السواقين بتنبيهات لحظية

بحث وتخطيط شامل لبناء نظام متابعة حركة خاص بالشركة، بديل لتطبيق **Life360**، فيه:
- ✅ تطبيق للسواق: **تسجيل حضور وانصراف بس**، والتتبع شغال لوحده في الخلفية.
- ✅ **تنبيه لحظي** لو السواق وقف أكتر من **30 دقيقة** (قابل للتعديل).
- ✅ **يشتغل من غير نت**: بيخزن كل نقطة بوقتها، ولما النت يرجع بيبعت كله بالترتيب (والتنبيهات المهمة الأول).
- ✅ داشبورد واحد لكل السواقين + تقارير وتحليلات وتقرير يومي آلي.

## ⚡ الخلاصة في سطور
1. **Life360 معمول للعائلات** مش للشركات: مفيش تنبيه وقوف، مفيش داشبورد مجمع، مفيش تصدير، هيستوري 30 يوم بس، وبياناتك بره مصر.
2. **الحل:** تطبيق Android (Kotlin أو Flutter + مكتبة Transistorsoft) + Backend (Node/Go + PostgreSQL/PostGIS/TimescaleDB + Redis) + داشبورد React عربي.
3. **سر الأوفلاين:** Outbox في SQLite + رقم تسلسلي لكل نقطة + رفع بأولوية + Idempotency على السيرفر + إعادة حساب الوقفات لما البيانات القديمة توصل.
4. **سر التنبيه اللحظي:** State لكل سواق في Redis + Timer كل 30 ثانية + Watchdog للانقطاع + Telegram/Push.
5. **سر البطارية:** Motion state machine (GPS عالي وهو ماشي، مقفول وهو واقف مع Geofence حوالين المكان).
6. **أقوى تحكم:** موبايلات شركة موحدة + MDM (يمنع السواق يمسح التطبيق أو يقفل الموقع).
7. **MVP في ~6-7 أسابيع** يحل المشكلة الأساسية، وتكلفة التشغيل ~$50-200/شهر لـ 100 سواق.
