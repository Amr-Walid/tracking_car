# 07 - الجانب القانوني والخصوصية (مصر) + سياسات الاستخدام

> ⚠️ ده **مش استشارة قانونية**. ده ملخص بحث عشان تعرف النقاط اللي لازم تراجعها مع محامي الشركة.

## 1. قانون حماية البيانات الشخصية المصري رقم 151 لسنة 2020

- الموقع الجغرافي للموظف = **بيانات شخصية** → القانون بيطبق.
- **اللائحة التنفيذية** صدرت بقرار وزير الاتصالات رقم **816 لسنة 2025**، ودخلت حيز التنفيذ **2 نوفمبر 2025**.
- **مهلة توفيق الأوضاع: سنة → آخرها 1 نوفمبر 2026** (يعني قريب جداً من تاريخ النهارده 21/10/2026). بعدها فيه غرامات وعقوبات.
- الجهة المسؤولة: **مركز حماية البيانات الشخصية (PDPC)** — pdpc.gov.eg

### أهم الالتزامات اللي تخص نظامنا
| الالتزام | التطبيق في المشروع |
|---|---|
| **غرض محدد ومشروع ومُعلن** | سياسة مكتوبة: "متابعة الحركة أثناء ساعات العمل لأغراض تشغيلية" |
| **موافقة صاحب البيانات** + إعلامه بالغرض | موافقة مكتوبة/إلكترونية من السواق عند أول تسجيل (نخزن نسخة منها + وقتها) |
| **إشعار خصوصية (Privacy Notice) بالعربي** وبلغة بسيطة | شاشة في التطبيق + نسخة PDF |
| **تقليل البيانات (Data minimization)** | **التتبع أثناء الوردية فقط**، ونقفل بعد الانصراف |
| **مدة احتفاظ محددة** ومسح بعد انتهاء الغرض | Retention policy (مثلاً 90 يوم للنقط، سنة للملخصات) + مسح آلي |
| **حقوق صاحب البيانات** (الاطلاع، التصحيح، الاعتراض...) | السواق يقدر يطلب تقرير ببياناته |
| **ترخيص/تصريح من PDPC** لأغلب عمليات المعالجة | (المعالجة أقل من 100,000 سجل معفية من رسوم الترخيص حسب التدرج — بس لسه محتاج ترخيص). راجع البوابة الإلكترونية لما تشتغل |
| **مسؤول حماية بيانات (DPO)** للأشخاص الاعتبارية | تعيين DPO أو مشترك |
| **سجل أنشطة المعالجة (RoPA)** | توثيق: إيه البيانات، ليه، مين يشوفها، قد إيه |
| **أمان البيانات** | تشفير، صلاحيات، Audit log |
| **إبلاغ عن الاختراق خلال 72 ساعة** للمركز، و3 أيام عمل لأصحاب البيانات | خطة Incident response |
| **نقل البيانات خارج مصر** محتاج **ترخيص منفصل + موافقة صريحة** | ⭐ **يُفضّل استضافة السيرفر جوه مصر** أو أخذ التصريح. (وده سبب إضافي إن Life360 مشكلة: بياناتك بتتخزن في أمريكا) |
| **الدليل الرقمي** معترف بيه لو محفوظ بطريقة تضمن السلامة | سجلات غير قابلة للتعديل (append-only) + hashes → تنفع لو فيه نزاع مع سواق |

## 2. قانون العمل
- يُفضل إضافة بند في **عقد العمل / لائحة الجزاءات الداخلية** إن السواق ملزم بتشغيل التطبيق أثناء الوردية، وإن التلاعب (قفل GPS / Fake GPS) مخالفة.
- السياسة لازم تكون معلنة وموقعة عشان أي جزاء مبني على بيانات السيستم يبقى سليم.

## 3. موبايل الشركة vs موبايل السواق الشخصي

| | موبايل شركة (موصى به) | موبايل شخصي (BYOD) |
|---|---|---|
| التحكم | كامل (MDM: منع المسح، منع قفل الموقع) | محدود |
| الخصوصية | أسهل قانونياً | لازم تتبع **في الوردية بس** وبشفافية |
| التكلفة | موبايل + شريحة (~3-5 آلاف ج للموبايل) | بدل داتا للسواق |
| الموثوقية | عالية (تختار موديل كويس مع الخلفية) | متغيرة (ماركات بتقتل التطبيقات) |
| التلاعب | صعب | أسهل |

**توصية:** موبايلات شركة رخيصة وموحدة (موديل واحد مجرب) + MDM = أفضل نتيجة. لو BYOD: تتبع في الوردية فقط + بدل داتا + توقيع السياسة.

## 4. بنود السياسة المقترحة (Template مختصر)
1. الغرض: متابعة الحركة لتحسين التشغيل وسلامة السواقين.
2. البيانات المجمعة: الموقع، السرعة، حالة البطارية والـ GPS، أوقات الحضور والانصراف، صورة الحضور (اختياري).
3. التوقيت: **من تسجيل الحضور لتسجيل الانصراف فقط.**
4. مين يطلع: المشرف المباشر، مدير العمليات، الموارد البشرية (للحضور فقط).
5. مدة الاحتفاظ: النقط التفصيلية 90 يوم، الملخصات 12 شهر.
6. مكان التخزين: سيرفرات داخل جمهورية مصر العربية.
7. حقوق الموظف وطريقة التواصل مع مسؤول حماية البيانات.
8. المخالفات: تعطيل التتبع أو التلاعب به أثناء العمل.
