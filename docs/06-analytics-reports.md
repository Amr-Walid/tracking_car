## 2. مؤشرات الأداء (KPIs) لكل سواق

| KPI | المعادلة | الفايدة |
|---|---|---|
| **وقت الوردية** | check_out − check_in | |
| **وقت الحركة** | Σ مدة الرحلات | |
| **وقت الوقوف المبرر** | Σ وقفات في geofence مسموح أو بسبب مقبول | |
| **وقت الوقوف غير المبرر (Idle)** ⭐ | Σ وقفات ≥ 10 د خارج الأماكن المسموحة / أو سببها "بدون مبرر" | **أهم مؤشر للهدر** |
| **نسبة الإنتاجية (Utilization)** | (حركة + وقوف مبرر) ÷ وقت الوردية | |
| **وقت الانقطاع** | Σ فترات بدون بيانات | يكشف اللي بيقفل الموبايل عمداً |
| **الكيلومترات** | Σ مسافة الرحلات (بعد فلترة القفزات) | مقارنة مع البنزين |
| **عدد الوقفات الطويلة** | count(stops ≥ 30 د) | |
| **عدد الزيارات** | وقفات في geofence عميل ≥ 5 د | |
| **متوسط مدة الزيارة** | لكل عميل/نوع عميل | |
| **أول حركة / آخر حركة** | first trip start, last trip end | بيبدأ متأخر؟ بيخلص بدري؟ |
| **وقت الوصول لأول عميل** | من الحضور لأول زيارة | |
| **الالتزام بالحضور** | % أيام الحضور في الميعاد | |
| **مخالفات السرعة** | count + مدة | السلامة |
| **التنبيهات** | count حسب النوع | |
| **مؤشرات التلاعب** | mock / gps_off / permission revoked / انقطاعات متكررة في أماكن فيها تغطية | |
| **Driver Score (0-100)** | معادلة موزونة (تحت) | ترتيب السواقين |

### معادلة الـ Score المقترحة (قابلة للتعديل)
```
Score = 100
  − 0.5 × (دقايق الوقوف غير المبرر ÷ 10)
  − 5   × عدد الوقفات الطويلة غير المبررة
  − 0.3 × (دقايق الانقطاع في أماكن فيها تغطية ÷ 10)
  − 3   × مخالفات السرعة
  − 10  × أحداث التلاعب (mock / gps off عمداً)
  − 2   × التأخير في الحضور (لكل 15 د)
  (حد أدنى 0)
```

## 3. التقارير

### 3.1 تقارير آلية (بتتبعت لوحدها)
| التقرير | الميعاد | المحتوى | القناة |
|---|---|---|---|
| **التقرير اليومي للاستثناءات** ⭐ | كل يوم 7:00 ص | **بس المشاكل**: مين وقف أكتر من 30 د وفين وكام مرة، مين انقطع، مين اتأخر، أعلى 5 Idle، أسوأ 5 Score | Email + Telegram + PDF |
| ملخص نهاية الوردية | بعد كل وردية | جدول كل السواقين بالـ KPIs | Dashboard + Email |
| التقرير الأسبوعي | السبت 8 ص | الترند، مقارنة الأسبوع باللي قبله، ترتيب السواقين، الأماكن الأكثر وقوف | Email PDF |
| الشهري | 1 من الشهر | للإدارة العليا + Payroll input (ساعات العمل) | Excel |

> ده بالظبط اللي بيحل مشكلة "بكتشف بعد 3-4 أيام": **أسوأ حالة هتعرف تاني يوم الصبح**، وأغلب الحالات لحظياً.

### 3.2 تقارير عند الطلب (Filters: تاريخ، فرع، سواق، مجموعة) + تصدير Excel/PDF
1. **تقرير الوقفات (Stops Report):** كل وقفة: السواق، البداية، النهاية، المدة، العنوان، التصنيف، السبب.
2. **تقرير الرحلات (Trips Report):** من/إلى، المسافة، المدة، السرعة القصوى/المتوسطة.
3. **تقرير الحضور والانصراف:** + التأخير + الساعات الإضافية + الحضور خارج المكان المسموح.
4. **تقرير الزيارات (Visits):** لكل عميل: مين زاره، إمتى، قعد قد إيه، عدد الزيارات في الفترة، العملاء اللي متزاروش.
5. **تقرير الوقت الضائع (Idle Time):** إجمالي وتفصيلي + تحويله لتكلفة (ساعة السواق × أجر الساعة).
6. **تقرير الكيلومترات:** لكل سواق/عربية + مقارنة مع استهلاك البنزين (لو بيتسجل).
7. **تقرير التنبيهات:** العدد، النوع، وقت الاستجابة (Ack time) لكل مشرف، نسبة False positive.
8. **تقرير صحة الأجهزة:** الموبايلات اللي فيها مشاكل بطارية/إعدادات/نسخة قديمة.
9. **تقرير التلاعب (Fraud):** mock، gps off، انقطاعات مشبوهة.
10. **تقرير الانقطاع والتغطية:** خريطة المناطق اللي النت بيقطع فيها + Detection delay.

## 4. التحليلات المتقدمة (Analytics)

| التحليل | بيجاوب على | الطريقة |
|---|---|---|
| **Heatmap الوقفات** | فين السواقين بيقفوا كتير؟ (قهاوي؟ أماكن تجمع؟) | تجميع مراكز الوقفات غير المبررة (DBSCAN / H3 hexagons) |
| **Hotspots مشتركة** | هل فيه مكان بيتجمع فيه سواقين كتير؟ | Clustering على كل السواقين + عدد السواقين المختلفين |
| **أنماط زمنية** | إمتى الهدر بيزيد؟ (بعد الضهر؟ يوم الخميس؟) | Heatmap يوم × ساعة للـ idle |
| **مقارنة السواقين / الفروع** | مين الأحسن ومين الأسوأ؟ | Leaderboard + Percentiles |
| **Trend** | الأداء بيتحسن بعد تطبيق السيستم؟ | Time series أسبوعي |
| **Anomaly detection** | سواق سلوكه اتغير فجأة | مقارنة باليوم بالمتوسط الشخصي (z-score) |
| **وقت الخدمة عند العملاء** | أي عميل بياخد وقت أطول من الطبيعي؟ | متوسط/وسيط مدة الزيارة لكل عميل |
| **تحليل المسارات** | السواق بيلف لفة أطول من المطلوب؟ | مقارنة المسافة الفعلية بأقصر مسار (OSRM) |
| **تكلفة الهدر** | الوقت الضائع بيكلفنا كام؟ | idle hours × أجر الساعة + km زيادة × تكلفة الكيلو |
| **تغطية الشبكة** | أي المناطق مفيهاش نت؟ | خريطة الانقطاعات |
| **Unvisited customers** | عملاء مهملين | العملاء اللي محدش زارهم من X يوم |

## 5. استعلامات SQL نموذجية

```sql
-- الوقفات الطويلة امبارح خارج الأماكن المسموحة
SELECT d.name, s.start_at, s.end_at, s.duration_s/60 AS minutes, s.address, s.driver_reason
FROM stops s JOIN drivers d ON d.id = s.driver_id
LEFT JOIN geofences g ON g.id = s.geofence_id
WHERE s.start_at >= current_date - 1 AND s.start_at < current_date
  AND s.duration_s >= 1800
  AND (g.id IS NULL OR g.type IN ('restricted','home'))
ORDER BY minutes DESC;

-- Heatmap: أكتر أماكن بيتوقف فيها (شبكة 200م)
SELECT ST_SnapToGrid(center::geometry, 0.002) AS cell,
       count(*) stops, count(DISTINCT driver_id) drivers, sum(duration_s)/3600.0 hours
FROM stops
WHERE geofence_id IS NULL AND start_at > now() - interval '30 days' AND duration_s >= 600
GROUP BY cell HAVING count(*) >= 5 ORDER BY hours DESC LIMIT 50;

-- ترتيب السواقين الأسبوع ده
SELECT driver_id, avg(score) score, sum(idle_unauthorized_minutes) idle_min, sum(distance_km) km
FROM daily_driver_stats WHERE day >= date_trunc('week', current_date)
GROUP BY driver_id ORDER BY score DESC;
```
